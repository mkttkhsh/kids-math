# kids-math — 娘の学習アプリ集（さんすう・ドイツ語・おんぷ）

GitHub Pages で公開する、子ども向けの学習アプリ集です（リポジトリ名は歴史的に kids-math のまま）。
1リポジトリに「メニュー（`index.html`）＋ アプリごとのフォルダ」を置く構成。
アプリが増えても **フォルダを1つ足してメニューにカードを1枚追加するだけ** で公開されます。

## 公開URL

- メニュー: `https://<ユーザー名>.github.io/kids-math/`
- 各アプリ: `https://<ユーザー名>.github.io/kids-math/<フォルダ名>/`

iPadの Safari で開き、「共有 → ホーム画面に追加」でアプリ化できます。

## 構成

```
kids-math/
├── index.html              ← アプリを選ぶメニュー画面
├── kazu-no-michi/
│   └── index.html          ← 数直線 ＋ 10のかたまり（位）
├── bunshoudai/
│   └── index.html          ← おはなしさんすう（文章題を3ステップで）
├── deutsch/
│   └── index.html          ← ドイツご あそび（ウィーン現地校むけ）
├── gakufu/
│   └── index.html          ← おんぷ あそび（五線譜の読み・書き・鍵盤）
└── README.md
```

## アプリの中身

### deutsch — ドイツご あそび
- レベル3段階: やさしい（4択・カタカナつき）／ふつう（6択・カタカナなし・フレーズは半分が「聞いて意味を選ぶ」）／むずかしい（似た語が選択肢・やり直し1回・つづり／文にダミータイル・レアシール）
- モード: きいて えらぶ（音声→絵）／みて いう（絵→ドイツ語）／がっこうの ことば（場面→フレーズ）／かず・ようび・つき／der・die・das（冠詞。青＝der 赤＝die 緑＝das）／つづり（文字・音節タイルを並べる。音節は `SYL` 表）／ぶんを つくる（単語タイルで語順）／タイムアタック（60秒・8問以上でシール・レベル別ベスト記録）／カードを みる
- 音声は iPad 内蔵の読み上げ（`speechSynthesis`、de-AT があればそれを優先、なければ de-DE）。API 不要・オフライン可
- 語彙: あいさつ・どうぶつ・いろ・がっこう・たべもの・数 1〜20・曜日・月（オーストリア式 Jänner）・学校で使うフレーズ約30
- 語彙を足すときは `<script>` 先頭の `WORDS` / `PHRASES` などの配列に1行追加するだけ

### gakufu — おんぷ あそび
- レベル: ト音記号 ド〜ソ → ド〜高いド → ヘ音記号 ド〜ソ → ド〜ド → 両手ミックス → 広い音域
- モード: よむ（音符→ドレミ）／かく（ドレミ→五線に置く）／ひく（音符→鍵盤）／きく（ド基準で音→鍵盤）／じゆうに ひく
- 音は Web Audio のシンセ、音部記号は Unicode グリフ（Apple Symbols）。外部ライブラリなし
- 音名はドレミのみ（ドイツ音名 C D E F G A H は未表示）

### 共通のご褒美
- 1セッション 10 問 → シール 1 枚（`localStorage` に保存、アプリ別の「シールちょう」で閲覧）
- 間違えても 2 回までやさしく再挑戦、3 回目で答えを見せて次へ。初回正解だけ ★

## 新しいアプリの足しかた

1. 新しいフォルダを作り、その中に `index.html` を置く
   例: `tokei/index.html`
2. ルートの `index.html` のカードのブロックをコピーして、
   `href` のフォルダ名・絵文字・タイトルを差し替える
3. `git add . && git commit -m "add tokei" && git push`
4. 数分後、`.../kids-math/tokei/` で公開される

各アプリの `index.html` は、他に依存しない **単体で完結したHTML** にしておくと管理がラクです。
